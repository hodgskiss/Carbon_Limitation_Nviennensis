# Carbon_Limitation_Nviennensis
Relevant scripts for the analysis of data in "Metabolic Response of a Chemolithoautotrophic Archaeon to Carbon Limitation" (Hodgskiss et al. 2025).
10.1128/MSYSTEMS.00732-25

## Proteomics
This folder contains scripts for the analysis of proteomic data in the manuscript.
Raw proteomic data can be found in the PRIDE proteomic database under Project PXD060602.
https://www.ebi.ac.uk/pride/archive/projects/PXD060602

## Metabolomics
Associated metabolomic data can be found in the MetaboLights repository under MTBLS11689.
https://www.ebi.ac.uk/metabolights/MTBLS11689
